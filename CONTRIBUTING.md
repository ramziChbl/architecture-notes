# Contributing to the Infrastructure Comparison Project

We welcome contributions to this project! Please follow these guidelines to ensure a smooth and collaborative process.

## How to Contribute

1.  **Fork the repository.**
2.  **Create a new branch** for your changes.
3.  **Add a new comparison** or **improve an existing one**.
4.  **Ensure your code is well-documented** and follows the existing structure.
5.  **Submit a pull request** with a clear description of your changes.

## Style Guide

*   **Terraform:** Follow the official [Terraform style conventions](https://www.terraform.io/docs/language/style.html).
*   **Markdown:** Use clear and concise language. Use headings, lists, and tables to organize your content.

## Questions?

If you have any questions, please open an issue on GitHub.
